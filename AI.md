# Робота з AI

*Заповніть один із двох варіантів і видаліть другий.*

## Якщо ви користувалися AI

**Інструменти й промпти** (ключові — дослівно):
"Допоможи адаптувати клас заявки та користувача під Java records для другої лабораторної."
"Як правильно написати switch-вираз у Java без використання default для переліку enum?"

**Що AI зробив неправильно або не так, як вимагає завдання, і як ви це помітили:**
Штучний інтелект спочатку запропонував залишити базовий клас BaseEntity для всіх моделей із загальним полем createdAt. Проте під час перевірки з умовами технічного завдання (ТЗ) я помітив вигонку з лаби: record у Java не може наслідувати інші класи, через що спадкування від BaseEntity заборонене і цей клас довелося повністю прибрати.

**Що виправили самостійно і чому:**
Самостійно переписав конструктори моделей на компактні (compact constructors) для коректної валідації полів у record. Самостійно налаштував синтаксис switch-виразів зі стрілками (->) та пересвідчився, що перший switch-вираз по enum Priority покриває всі константи й не містить гілки default, як того суворо вимагають інструкції до лабораторної роботи.
